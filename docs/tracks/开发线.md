### 手机走查的一个坑（下次注意）

`adb install` 一开始报 `SecurityException: Caller has no access to session -1`，`push` + `pm install` 也一样——是 ROM 的「通过 USB 安装」权限没开（当时只有「USB 调试」是开的）。用户在开发者选项里打开之后，`adb install -r` 立刻成功。下次装包前先试一条 `adb shell pm install-create -r -S <字节数>`，成功就说明权限通了。
