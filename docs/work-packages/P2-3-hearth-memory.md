# P2-3 炉边记忆：沉浸模式下，每个人物记得和你聊过的事

- 仓库 / 基准提交：安卓仓库 `main`（P2-2 合并后）
- 分支：`wp/P2-3-hearth-memory`
- 工作目录：`D:\Agent\Project\Nivra`
- 依赖：P2-2 已合并；P2-1d、P2-3b 合并以后开工（三个包都改炉边的提示拼法）。
- 规模：5–7 个工作日。
- 背景：
  - 2026-10-18 用户决定：沉浸模式下，每个人物会记录聊天内容、形成自己的记忆，下次聊天能想起来。**每个人物的记忆彼此独立**，就像现实里每个人对你的印象和记忆都不一样。测试模式不留任何记录。
  - 总计划阶段 2 的 P2-3「记忆 v1」原定：提取、检索、重要度、去重，用户可以查看、修改、让人物忘掉。本包按这个做，并加上「按人物独立」。
  - **2026-10-24 补充**（用户看了同类 App 后定下借鉴）：记忆要「看得见、管得了」。除了查看、修改、删除、清空，还要能**钉住**和**手动添加**，见第 4 步。
  - **2026-10-24 补充**：P2-1d 靠「同一段对话每一轮的提示前缀不变」来复用检查点。记忆放进提示的位置必须照顾这一点，见第 3 步，否则每轮都会整段重读，又回到等 90 秒。

## 目标（用户能得到什么）

- 和「老周」说过「下周三去面试」，过几天新开一段对话问「你还记得我下周要干嘛吗」，它答得出来。
- 「猫」不知道你和「老周」说过什么。
- 在人物页能看到「它记得的事」，可以改、可以删，也可以一键让它全部忘掉。

## 步骤

1. **记忆条目**：存在炉边的加密库里，按人物分开。删除人物时，它的记忆一起删。每条记忆包括：
   - 内容：一句话；
   - 类型：关于你的事实、发生过的事、你的偏好、约定；
   - 出自哪段对话、什么时间；
   - 重要度；
   - 最近一次被用到的时间。
2. **写入（只在沉浸模式）**：
   - 一段对话告一段落时（离开对话页、点「新对话」，或者连续聊了 N 轮），用这个人物自己的模型，从新增的对话里抽取记忆。抽取提示的模板写在代码里，并有单测。
   - 在后台做，不卡界面；抽取失败或输出格式不对，就跳过这次，不影响聊天，也不写入半截内容。
   - 去重：和已有记忆说的是同一件事时，更新原来那条，不新增一条。
3. **读取（只在沉浸模式）**：
   - **一段对话开始时**检索一次这个人物的记忆：全文检索，加上重要度、新近程度，钉住的优先。取前 K 条，放进系统提示，标明「你记得的关于对方的事」。**这一段对话里不再变动**。
   - 这段对话里新抽取出的记忆，从下一段对话起生效。
   - 例外：用户在对话里明确问「你还记得……吗」时，可以按这一轮的问题再检索一次，结果放在**本轮用户消息的前面**，不改动前缀。方案里写清楚具体做法，并量一下对检查点复用的影响。
   - 放进提示的记忆总长度有上限，超了按重要度截掉，钉住的最后截。
   - 检索只查当前人物的记忆。
   - 测例：同一段对话连续几轮，系统提示逐字不变。
4. **界面：人物页增加「它记得的事」**
   - 列表：按类型分组，显示出自哪天的对话。
   - 编辑一条、删除一条、全部清空（要确认）。
   - **钉住**：钉住的那条，每段对话都带上；去重时不会被合并掉，自动整理也不会删它。
   - **手动添加**：用户自己写一条，比如「我对芒果过敏」，直接存成这个人物的记忆，默认钉住。
   - 用户编辑过或手动添加的条目，以后自动抽取时不覆盖。
5. **云端人物**：记忆会随提示发给云端。P2-2 的确认弹窗文字要明确写出「它对你的记忆」。
6. **测试模式**：不读、不写记忆。

## 验收标准

- [ ] JVM 测试（用假模型返回固定的抽取结果）：
  - 抽取、去重、检索排序、长度上限；
  - **独立性**：A 的记忆在任何情况下都不会出现在 B 的提示里；
  - 测试模式不读也不写记忆；
  - 删除人物时，它的记忆一起删除；
  - 加密库里搜不到记忆的明文；
  - 老版本的库能升级；
  - 钉住的不被去重合并、不被截掉、每段对话都带上；手动添加的、用户编辑过的，不被自动抽取覆盖；
  - **同一段对话连续几轮，系统提示逐字不变**（保护 P2-1d 的检查点复用）。
- [ ] 测试夹具里至少有一组照真实聊天形状造的数据：中英文夹杂、带表情、很长的一段话、有日期和时间的说法。
- [ ] 真机（红魔，用手机前先问用户）：
  - 和「阿远」聊一段，里面带两三件具体的事（例如「下周三去面试」「我不吃香菜」）；结束对话，等抽取完成，记下抽取用了多久（用 4B）；
  - 新开一段对话问「你还记得我下周要干嘛吗」，能答出来；
  - 在「它记得的事」里删掉这一条，再问就答不出来；
  - 手动添加一条「我对芒果过敏」，新对话里问「我能吃芒果吗」，它记得；
  - 问「年糕」同样的问题，它答不出来；
  - 测试模式下说一件新事，退出后，「它记得的事」里没有它；
  - 带着记忆连聊 4 轮，第 2 轮起检查点照样用得上（读数里 `reused > 0`）。
