## 做了什么

- 新增 `:net`。它是唯一做 HTTP 的模块，对外是出网网关。检查更新改走这个网关，解析和「没有发布版 / 有新版本 / 已是最新」的结果没变。
- 新增 `:roundtable`。它检索、拼提示、校验回答、估算费用，通过网关发请求，不依赖 HTTP 库。`:contract` 仍是纯 Kotlin。
- 架构测试读 `settings.gradle.kts`：除 `:net` 外，任何模块的构建脚本和 `src/main` 都不得出现 `okhttp`、`retrofit`、`ktor`、`java.net.http`、`HttpURLConnection`、`openConnection`。名字以 `companion` 开头的模块不得依赖 `:net`。现在还没有伴侣模块，这条是事先写好的。
- 白名单：更新只允许 https 的 `api.github.com`、`github.com`、`objects.githubusercontent.com`；圆桌聊天只允许用户配置的接口地址。明文只在 debug 包、并且地址是 `http://127.0.0.1` 时放行。`localhost` 和其他局域网地址不放行。正式包的 `usesCleartextTraffic` 仍是 false。
- 每次真正发出的请求写一条本地审计：时间、域名、用途（更新 / 圆桌聊天）、发送字数、发送正文、状态码、成败、费用估算。正文不含密钥和认证头。白名单拒绝的请求不发出，也不记审计。
- 「我的 → 云端模型」可填接口地址、模型名、API key、输入和输出单价、每月上限。保存后密钥框清空，只显示末 4 位。密钥用 Keystore 的 AES-GCM 包装，不进日志、审计、代码和截图。

## DeepSeek 核对

核对日期 2026-10-17。来源：

- 创建对话补全：`https://api-docs.deepseek.com/api/create-chat-completion`
- 模型与价格：`https://api-docs.deepseek.com/quick_start/pricing`
- 思考模式：`https://api-docs.deepseek.com/guides/thinking_mode`
- 隐私政策：`https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html`（更新并生效于 2026-02-10）

默认值：

- 接口地址 `https://api.deepseek.com`，路径 `POST /chat/completions`。不用 Anthropic 兼容地址。
- 模型 `deepseek-flash`。文档写明用这个名字。
- 单价按非高峰、缓存未命中：输入 0.15 美元 / 百万 token，输出 0.6 美元 / 百万 token。高峰是工作日 UTC 01:00–04:00 和 06:00–10:00（中国法定节假日除外），非高峰是高峰的一半。缓存命中更便宜，估算不按命中计算，所以偏高。
- 每月上限默认 5 美元。
- 请求带 `response_format: {type: json_object}`。思考默认开着，请求里用官方 OpenAI 形式关掉：`thinking: {type: disabled}`。
- 隐私政策「智能对话」说产品里的对话可能用于训练，并且可以在产品里关闭。同一份政策的「开放平台服务」和开放平台协议都没有写 API 输入会不会用于训练。界面因此写「未找到明文条款」，并给出上面的隐私政策地址。

创建对话补全那一页没有列出 401 和 429 的对照表。客户端仍把 401 显示为「云端拒绝了密钥（401）」，把 429 显示为「云端限流（429），这次没有回答」，因为任务书要求覆盖这两种响应。
