# 知衍 0.4.0 更新说明

这是知衍（Mycelium）安卓版的**第一个正式版本**。上一个正式版是 2026-10-09 的 0.1.1；中间的 0.2.0、0.3.0 没有发布过，它们的功能全都合进了这一版。

## 这一版能做什么

**圆桌**：把电脑版知衍导出的人物包传进手机，导入后就能在「圆桌」里放多个角色。要先在「我的 → 云端模型」里添加自己的云端服务（地址和 key）、拉取模型列表并勾选要用的模型。

**炉边**：这里的人物由你自己写，人物设定和对话都只留在手机上。默认用手机上的本地模型，不联网、不耗流量；也可以给某个人物单独改用云端模型——改之前 App 会先列出「哪些内容会发出去」（人物设定、你这轮问的话、以前的对话），你确认后才生效，之后随时可以改回本地模型。

**本地模型**（「我的 → 本地模型」）：自己准备 GGUF 文件并导入，模型在手机上离线运行。

**云端模型**（「我的 → 云端模型」）：自己添加服务、填地址和 key，然后拉取并勾选要用的模型。key 加密保存在手机本地，不会跟着应用更新走。

**应用内更新**（这一版新增）：

- **自动检查**：打开 App 时在后台查一次有没有新版本，一天最多一次，不挡界面、也不弹窗；检查失败不打扰你，只有手动点「检查更新」才会显示失败原因。
- **有新版本时**：「我的」上出现一个小红点，页面顶部出现一张卡片，写着版本号、安装包大小和这一版的中文更新说明。
- **下载并安装**：点一下就开始下载，能看到进度，中途可以取消。下载完 App 会自己核对四项——安装包完整（内容和发布方给的校验值一致）、包名对、签名和现在装着的知衍一致、版本号比现在高。任何一项不对就删掉文件、不安装，并用中文告诉你哪一项不对。
- **系统确认**：核对通过后，系统会弹出安装确认界面，点「安装」就升级好了，数据都在。Android 不允许 App 自己静默安装，所以这一步**必须你亲手点**（一共两下：App 里一下、系统界面一下）。
- **不想升级**：点「忽略这个版本」，这一版就不再提示，出了更新的版本会再提示；也可以在「我的」里关掉「自动检查更新」，只留手动按钮。

## 怎么升级到 0.4.0

- **手机上装着 0.1.1**：这一次只能用老办法——用手机浏览器打开发布页 <https://github.com/plnoble/Mycelium-Android/releases/latest>，下载 `mycelium-v0.4.0.apk` 安装；或者用数据线装。0.1.1 里的「检查更新」只会在浏览器里打开下载地址，它没有应用内安装，也不会执行上面那四项校验（那四项从 0.4.0 才开始、只在应用内安装这条路上跑）。
- **0.4.0 以后**：可以直接在 App 里点「下载并安装」，两次点击就升上去。
- **正式包只支持 64 位 ARM 系统**：CPU 是 64 位**不**等于系统一定能装 `arm64-v8a` 的包。**32 位 ARM 系统的手机不要覆盖升级到这一版**（会失败或装不上），请留在 0.1.1；不要为了装 0.4.0 去卸载重装，卸载会丢数据。调试包仍然包含全部架构，方便在模拟器上用。
- **升级不会丢数据**：**0.1.1 是阶段 0 的外壳，里面没有人物、对话这些业务数据**，所以从 0.1.1 升上来时手机上本来就没有业务数据可丢，这次升级只证明「升级不会把应用的数据目录清空」。从 0.4.0 起，人物、对话、导入的人物包、本地模型登记和云端服务设置都存在手机里，以后的升级会保留；想更稳妥，升级前自己先备份一份。
- **认准正式签名**：每个正式包都用同一张证书签名，指纹（公开信息）写在仓库的 `docs/releases/signing-cert-sha256.txt`。别装来路不明的「知衍」——那种包因为签名不同，也覆盖安装不了正式版。

## 已知问题

- **本地模型第一轮回答慢**：现在的引擎每问一轮都会把提示从头读一遍，提示长的时候要等几十秒。这一条留到下一个版本改（复用已经读过的上下文）。
- **要自备模型和云端服务**：App 不附带本地模型文件，也不附带任何云端额度。云端服务和 key 都得自己准备；不用云端、只用本地模型也完全可以。
- **本地模型文件不打进安装包**：模型几 MB 到几 GB，混在应用更新里会费流量。以后会在「我的 → 模型」里单独下载、单独管理——应用更新和模型更新是两套。
- **升级前请知悉**：第一次把某个人物改用云端模型时，请确认你接受把该人物设定、你的提问和以前的对话发给那家云端服务。
