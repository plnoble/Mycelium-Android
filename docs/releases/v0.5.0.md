# 知衍 0.5.0 更新说明

这一版的主角是**本地对话变快**。上一个版本是 0.4.0，从这一版起你可以直接在 App 里升级——不用再连数据线、也不用开浏览器。

## 这一版能做什么

**本地对话明显变快**：

- **用上了手机 CPU 的快速计算方式**：App 会自动识别你的手机支持哪些加速指令，挑最快的一套来跑本地模型。同样的提问，读取提示的速度最高能快到原来的三倍左右。
- **同一段聊天里，不再每句都从头读**：以前每问一句，App 都要把这段对话从头到尾重新读一遍才能回答；现在从第二轮起，只把**新增的那几句话**交给模型，之前的内容直接沿用。对话越长，省下的等待越多——长对话里原来要等几十秒的读取，现在一般一秒上下。
- 用词说明：上面说的都是「同一个人、同一段对话」里的加速；换一个人物、换一段对话，App 会自动换一套对应的内容，不影响正确性。

**本地模型等太久会有提示**：按下发送后，如果模型 20 秒还没有开始出字（通常说明这段提示比较长、正在读取），界面会出现一条提示告诉你情况，你可以继续等它答完。

**第一次真正的应用内升级**：0.4.0 里装好的「下载并安装」这一版就能用上了——打开知衍 →「我的」→ 点检查更新，看到 0.5.0 的卡片后点「下载并安装」，下载完系统会让你确认一下，两下点击就升级完成，人物、对话、模型登记都在。

## 怎么升级到 0.5.0

- **手机上装着 0.4.0**：直接在 App 里点「下载并安装」（见上）。这是第一次完整走应用内升级：下载 → App 自动核对（安装包完整、包名对、签名一致、版本号更高）→ 系统确认 → 安装完成。
- **手机上还装着 0.1.1**：还是老办法——用手机浏览器打开发布页 <https://github.com/plnoble/Mycelium-Android/releases/latest>，下载 `mycelium-v0.5.0.apk` 安装；0.1.1 没有应用内升级，这是预期行为。
- **正式包只支持 64 位 ARM 系统**：32 位系统的手机不要覆盖升级（会失败），请留在当前版本；卸载重装会丢数据。
- **升级不会丢数据**：人物、对话、导入的人物包、本地模型登记和云端服务设置都留在手机里。想更稳妥，升级前自己先备份一份。
- **认准正式签名**：每个正式包都用同一张证书签名，指纹（公开信息）见仓库的 `docs/releases/signing-cert-sha256.txt`。别装来路不明的「知衍」。

## 已知问题

- **不是所有手机都能用上快速计算方式**：它要求 CPU 支持比较新的一组指令，大约是 2022 年以后的旗舰芯片才有（比如骁龙 8 Gen 1 及更新的型号）。更早或中低端的手机会自动改用基础版：能正常用，只是读提示没有快三倍。这一切都是自动的，不会报错，也不用设置。「同一段聊天不再每句从头读」这一项，所有手机都有。
- **本地模型第一句仍可能要等**：换一个人物、换一段新对话的第一问，还是要从头读一遍提示（人物设定 + 你的第一句话）；之后的每一句才会走上面说的加速。提示越长，第一句等待越久。
- **要自备模型和云端服务**：App 不附带本地模型文件，也不附带任何云端额度。不用云端、只用本地模型也完全可以。
- **本地模型文件不打进安装包**：模型几 MB 到几 GB，混在应用更新里会费流量。单独的「模型下载与管理」在后面的版本里做——应用更新和模型更新是两套。
